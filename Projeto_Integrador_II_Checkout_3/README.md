# Projeto Integrador II — Módulo 3

Evolução da solução de pesquisa de preços com banco de dados relacional e controle de versão.

Tecnologias: Python, SQLite, SQL, Flask, Vue.js 3, HTML5, CSS3 e Git.

Banco: `catmat_itens` 1:N `consultas` 1:N `registros_precos`. O esquema está em `sql/schema.sql`; exemplos de INSERT, SELECT, UPDATE e DELETE estão em `sql/crud_examples.sql`.

Execução: `python -m venv .venv`, ativar, `pip install -r requirements.txt`, `python init_db.py`, `python app.py`, abrir `http://127.0.0.1:5000`.

Testes: `pytest -q`.

GitHub: https://github.com/gcampos-UFMS/projeto-integrador-CATMAT
Organização sugerida: `Projeto_Integrador_II_Checkout_3`.
